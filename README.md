# HR Analytics Dashboard using Power BI

## 📌 Project Overview
This project focuses on analyzing HR data using Microsoft Power BI to understand employee attrition, workforce demographics, salary distribution, job satisfaction, and department-wise employee trends.

## 🎯 Objectives
- Analyze employee attrition and attrition rate.
- Understand workforce distribution by department and job role.
- Explore employee demographics such as age and gender.
- Analyze salary distribution and job satisfaction.
- Build an interactive dashboard to support HR decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

## 📊 Key Dashboard Features
- Employee KPI cards
- Attrition analysis
- Department-wise employee distribution
- Age and gender analysis
- Salary and job satisfaction analysis
- Interactive slicers and filters

## 📁 Project Files
- `HR_Analytics_Dashboard.pbix` — Power BI dashboard file
- `HR_Analytics.csv` — Dataset, if redistribution is permitted
- `Dashboard_Screenshot.png` — Dashboard preview

## 💡 Key Learnings
- Data cleaning and transformation using Power Query
- Creating DAX measures and KPIs
- Designing interactive Power BI reports
- Analyzing HR metrics and presenting business insights
